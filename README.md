# 대항해시대 2 웹 플레이어 (SNES 버전)
# Uncharted Waters 2 Web Player (SNES Edition)

**한글** — 브라우저에서 바로 플레이하는 대항해시대 2 (슈퍼 패미컴/SNES) 웹 에뮬레이터입니다.
설치 없이 웹페이지에 접속해서 본인이 보유한 ROM을 불러오면 실행됩니다. 모바일에서도 가상 게임패드로 플레이할 수 있습니다.

**English** — A browser-based emulator frontend for *Uncharted Waters: New Horizons* (Super Famicom / SNES edition).
No installation required — just open the site and load your own ROM. Playable on mobile with an on-screen gamepad.

## 플레이 사이트 / Play Here

https://unopndjude.github.io/uncharted-waters-2-snes/

## 플레이 방법 / How to Play

**한글**
1. 위 "플레이 사이트" 링크로 접속합니다.
2. 화면의 **"ROM 업로드"** 버튼을 클릭합니다.
3. 준비한 `.sfc` 또는 `.smc` 파일을 선택합니다.
4. 잠시 로딩 후 게임이 시작됩니다.

**English**
1. Open the **Play Here** link above.
2. Click the **"Upload ROM"** button on the page.
3. Select your `.sfc` or `.smc` file.
4. After a brief load, the game starts.

## 저장 / Save Data

**한글**
- **게임 내 저장** (배 안에서 일기 작성): ROM에 포함된 저장 기능이며, 브라우저에 자동 저장됩니다.
- **상태 저장 (Save State)**: 에뮬레이터 UI에서 언제든 현재 상태를 스냅샷으로 저장/불러오기 할 수 있습니다.
- 저장 데이터는 **브라우저별, 기기별로 분리**됩니다. 다른 브라우저나 다른 PC에서는 보이지 않습니다.
- 시크릿/프라이빗 모드나 브라우저 데이터 삭제 시 세이브가 사라질 수 있으니 주의하세요.
- 에뮬레이터 UI에서 세이브 파일을 파일로 내보내/가져오기 할 수 있습니다 — 백업 권장.

**English**
- **In-game saves** (e.g. the captain's log): handled by the ROM, stored in your browser.
- **Save states**: use the emulator UI to snapshot and restore the exact game state at any time.
- Saves are **isolated per browser and per device**. They will not appear in a different browser or machine.
- Incognito/private mode or clearing browser data may wipe your saves.
- You can export/import save files in the emulator UI — back them up regularly.

## 자주 묻는 질문 / FAQ

**한글**

Q. 모바일에서 되나요?  
A. 네, 화면에 가상 게임패드가 자동으로 나타납니다. 가로 모드 권장.

Q. 한글화된 ROM도 되나요?  
A. 네, 본인이 보유한 한글 패치 ROM을 그대로 사용할 수 있습니다.

Q. 음악이 안 나와요.  
A. 브라우저 자동재생이 차단됐을 수 있습니다. 페이지를 한 번 클릭해 주세요.

Q. 게임이 너무 빠르거나 느립니다.  
A. 에뮬레이터 설정에서 속도(Speed)를 조정할 수 있습니다.

Q. 저장 데이터가 사라졌어요.  
A. 브라우저 데이터를 지웠거나 시크릿 모드로 접속하셨는지 확인하세요. 백업 파일이 있다면 UI에서 가져올 수 있습니다.

Q. DOS 버전과 무엇이 다른가요?  
A. SNES 버전은 가상 게임패드 지원으로 **모바일 친화적**이며 구동도 쉽습니다. DOS 버전은 고해상도·풍부한 사운드가 장점입니다. 아래 "다른 버전" 참고.

**English**

Q. Does it work on mobile?  
A. Yes, the on-screen gamepad appears automatically. Landscape mode recommended.

Q. Can I use a translated ROM?  
A. Yes, use your own translated ROM as is.

Q. No sound.  
A. Browser autoplay may be blocked. Click the page once to unlock audio.

Q. The game is too fast or too slow.  
A. Adjust speed in the emulator settings.

Q. My saves disappeared.  
A. Check whether you cleared browser data or used incognito mode. If you have a backup file, import it via the UI.

Q. How does this differ from the DOS edition?  
A. SNES is **mobile-friendly** (touch gamepad) and simpler to set up. DOS offers higher resolution and richer audio. See "Other Editions" below.
